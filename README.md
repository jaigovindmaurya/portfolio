## How to Deploy on GitHub Pages

1. Create a new repository on GitHub (e.g. `portfolio` or `jaigovind-portfolio`).
2. Upload all files from this folder (`index.html`, `style.css`, `script.js`, `README.md`).
3. Go to **Settings → Pages**.
4. Under **Source**, select the branch `main` (or `master`) and folder `/ (root)`.
5. Click **Save**. Your site will be live in 1–2 minutes.
